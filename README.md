# review-board

自分が出した PR、自分がレビューした・レビューを依頼された PR、それ以外のオープン PR、直近マージされた PR を一覧するローカルダッシュボード。`gh` CLI の認証を使って GitHub GraphQL API から取得する。

## 表示内容

| 表                | 対象                                                                                                             | 「要対応 / 返信あり / レビュー依頼」になる条件                                                                                                                                                                    |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 自分が出した PR   | `is:pr is:open author:@me`                                                                                       | 自分の最後のコメント・レビューより後に他人のコメント・レビューがある、または未返信の未解決スレッドがある                                                                                                          |
| レビュー担当の PR | `is:pr is:open reviewed-by:@me -author:@me` と `is:pr is:open review-requested:@me -reviewed-by:@me -author:@me` | レビュー済みのもの: 自分の最後のコメント・レビュー・コミットより後に、PR 作者のコメント・レビュー、または自分以外のコミットがある。未レビューでレビューを依頼されているもの: 「レビュー依頼」(下書きは「下書き」) |

### 要対応の判定

- 自分が出した PR で自分のコメント・レビューが無いときは、作成以降の他人のコメント・レビューをすべて新規として数える
- 自分が出した PR では、コミットは自分・他人どちらの動きにも数えない。push だけでは「要対応」から外れない。新規コメントは自分のコメント・レビューで外れる
- コメント・レビュー・スレッドのコメントに自分が 👀 以外のリアクションを付けると、そのコメントまでを対応済みとして扱う。返信せずに「確認した」で済ませたいときに使う
- 解決済みスレッドのコメントは「新規コメント」「返信」に数えない。自分のコメントは対応済みの判定には使う
- PR 作者のアカウントが削除されている場合は、コミットだけを返信に数える
- 本文が空の COMMENTED レビューは数えない (中身のインラインコメントを個別に数える)
- 送信していないレビュー (Pending) とそのインラインコメントは数えない

### 表示

- 「スレッド (未返信/未解決)」は未解決スレッドの数と、そのうち未返信 (最後の発言が自分でなく、最後のコメントに自分の 👀 以外のリアクションも無い) ものの数
- 「自分のスレッド (解決済み/全体)」は自分が始めたレビュースレッドの数と、そのうち解決済みの数。インラインコメントをしていなければ `0 / 0`
- Draft は状態を「下書き」と表示し、表の最下段に並べる。要対応の件数には数えない
- レビュー担当の PR のうち自分が最後に承認したものは、状態を「承認済み」(下書きなら「下書き」) と表示し、返信があっても要対応の件数に数えない。既定で隠し、表の上のチェックで表示する
- 既読の記録は持たない

### モーダル

- 「担当外のオープン PR」と「直近マージされた PR」はトップに表示せず、画面上部のボタンでモーダルとして開く
- 「担当外のオープン PR」は、自分が貢献したリポジトリ (GitHub の `repositoriesContributedTo`: コミット・Issue・PR 作成・PR レビュー) のうちアーカイブされていないものを対象に、`is:pr is:open -author:@me -reviewed-by:@me -review-requested:@me` で検索する。トップの表に出る PR は含まない。最終コミット時刻 (コミット無しなら作成時刻) の新しい順で、Draft は最下段
- 「直近マージされた PR」は、担当外のオープン PR と同じリポジトリで、UTC で 14 日前の日付の 0 時以降にマージされた PR (開始時刻はモーダルに表示する)。日付ごとに区切って新しい順に並べる

### 取得の上限

検索はどれも更新の新しい順 (`sort:updated-desc`) に並べ、上限まで取る。

| 対象                               | 上限                  | 超えたとき         |
| ---------------------------------- | --------------------- | ------------------ |
| 自分が出した PR・レビュー担当の PR | 検索ごとに先頭 50 件  | 件数の横に表示する |
| 担当外のオープン PR・直近マージ    | 検索結果の先頭 100 件 | 件数の横に表示する |
| 対象リポジトリ                     | 100 件                | モーダルに表示する |
| 1 PR のコメント・レビュー          | それぞれ最新 50 件    | 表示しない         |
| 1 PR のレビュースレッド            | 最新 50 件            | 表示しない         |
| 1 スレッドのコメント               | 最新 30 件            | 表示しない         |
| 1 PR のコミット                    | 最新 1 件             | 表示しない         |

## セットアップ

```bash
uv sync
uv tool install pre-commit
pre-commit install
```

`gh auth status` でログイン済みであること。

## 実行

```bash
uv run python src/main.py
```

ブラウザで `http://127.0.0.1:8765/` が開く (`--no-open` を付けると開かない)。オプションは `--help` を参照。

- サーバーは最後に取得した内容をメモリに持ち、画面やモーダルを開くとまずそれを表示してから、最新を取り直して差し替える
- 自分が出した PR・レビュー担当の PR は、画面を開いている間は 5 分ごとに、「今すぐ更新」を押したときは即時に取り直す
- 担当外のオープン PR・直近マージされた PR は、モーダルを開いたときだけ、対象リポジトリの一覧と合わせて取り直す
- 画面を開いていない間は GitHub に問い合わせない

### ログイン時に自動起動する (macOS)

```bash
scripts/launch-agent.sh install    # 登録して起動。再実行すると登録し直す
scripts/launch-agent.sh status     # 起動状態を表示
scripts/launch-agent.sh uninstall  # 停止して登録を外す
scripts/launch-agent.sh --help     # 使い方を表示
```

`~/Library/LaunchAgents/local.review-board.plist` を作り、ログイン時に起動、落ちたら再起動する。実行時の `uv` と `gh` の場所を plist に書き込むので、どちらかを入れ直して場所が変わったら `install` をやり直す。リポジトリを移動したときも同じ。ログは `~/Library/Logs/review-board.log`。

### アプリとして Dock に置く (Chrome)

1. Chrome で `http://127.0.0.1:8765/` を開く
2. 「⋮」メニュー →「キャスト、保存、共有」→「Review Board をインストール」(無ければ「ページをアプリとしてインストール」)
3. 開いたウィンドウの Dock アイコンを右クリック →「オプション」→「Dock に追加」

```bash
qlmanage -t -s 512 -o /tmp src/static/icon.svg
sips -z 512 512 /tmp/icon.svg.png --out src/static/icon-512.png
sips -z 192 192 /tmp/icon.svg.png --out src/static/icon-192.png
```
